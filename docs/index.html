🐒 Smoke Monkey Canvas v1.3.1

Autonomous Spatial Multi-Agent Workspace

Deploy, schedule, and orchestrate unlimited autonomous AI agents on an infinite visual canvas. Powered by Smoke Monkey Harness with local SQLite persistence, MCP servers, and instant NPX execution.

$ npx smoke-monkey-canvas --daemon
✔ Smoke Monkey Canvas active at http://localhost:3333
★ View on GitHub ☁️ Cloud Deploy 🐳 Docker & CLI Docs
🗺️

Infinite Spatial Canvas

Pan, zoom, drag, and connect AI agents spatially with real-time multi-agent orchestration and status badges.

⚡

Instant NPX & Daemon Mode

Run directly via npx smoke-monkey-canvas or fork into background daemon mode with automatic browser pop.

🐳

Production Docker & Compose

Deploy in seconds with Docker Compose. Includes isolated SQLite data volumes and dedicated PostgreSQL MCP services on port 15432.

🔌

Model Context Protocol (MCP)

Integrate any custom stdio or SSE MCP server. Paste Claude Desktop or Cursor configurations directly to import instantly.

⏰

Autonomous Cron Scheduling

Set custom cron expressions for background agent tasks without polluting interactive multi-turn chat threads.

🔒

100% Local & Private

Zero cloud lock-in. All agent definitions, settings, encrypted API keys, and chat sessions are stored locally in SQLite.
